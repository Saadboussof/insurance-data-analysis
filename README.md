## 🌟 Overview
Welcome to the **Machine Learning Analysis Project**. This repository serves as a centralized hub for end-to-end data pipelines, encompassing data exploration, feature engineering, and robust predictive modeling. From deep-diving into insurance datasets to classifying complex fashion images, this project demonstrates real-world AI applications.

## ✨ Key Features
- **📊 Exploratory Data Analysis (EDA):** Deep statistical insights and data visualizations.
- **🤖 Predictive Modeling:** Supervised learning algorithms covering both Regression and Classification.
- **⚙️ Data Augmentation:** Advanced scripts to manipulate and expand dataset dimensions (`dataAug.py`).
- **📓 Automated Workflows:** Easily executable, step-by-step Jupyter Notebooks.

## 📂 Project Architecture

```text
📦 ML_project
 ┣ 📂 data/          # Raw and processed datasets (Ignored by Git for storage efficiency)
 ┣ 📂 notebooks/     # Interactive Jupyter workspaces

 ┃ ┣ 📜 regressionInsurance.ipynb

 ┃ ┣ 📜 dataAug.py       # Data augmentation utilities
```

## 🚀 Getting Started

### Prerequisites
Ensure you have Python 3.8+ installed along with standard data science libraries (Pandas, NumPy, Scikit-Learn, Jupyter).

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Saadboussof/insurance-data-analysis.git
   cd insurance-data-analysis
   ```
2. **Prepare the Data:**
   Place your dataset files (`.csv`) such as the Fashion-MNIST or Insurance datasets directly into the `data/` directory.

## 🧠 Usage
Fire up the Jupyter server and explore the machine learning models:
```bash
jupyter notebook
```
Navigate to the `notebooks/` directory and open `classification.ipynb` or `regressionInsurance.ipynb` to execute the cells and see the predictions in action.
