# Machine Learning Data Analysis Project

Welcome to the Machine Learning Project! This repository contains various scripts and notebooks for data exploration, augmentation, and predictive modeling (such as regression and classification).

## 📂 Project Structure

- **`notebooks/`**: Contains Jupyter Notebooks used for exploratory data analysis (EDA) and training models.
  - `classification.ipynb`
  - `regressionInsurance.ipynb`
  - *etc.*
- **`src/`**: Contains Python source code.
  - `dataAug.py`: Data augmentation scripts.
  - Test scripts (`test2.py`, `testo.py`).
- **`data/`**: (Ignored by Git) Local datasets in `.csv` format (like Fashion-MNIST and Insurance datasets).

## 🚀 Getting Started

1. Clone this repository.
2. Place your `.csv` dataset files into the `data/` directory (these are ignored by Git to avoid uploading large files).
3. Run the Jupyter notebooks in the `notebooks/` directory to see the analysis and models.

## 🛠️ Built With
- Python
- Jupyter Notebook
